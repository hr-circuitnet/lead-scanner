📖 About This Tool

CircuitNet Expo Lead Scanner captures, manages and exports exhibition leads. All data syncs to a central cloud database — every logged-in user works on the same live data from any device.

📷 Capture Leads

Scan Badge — Opens the camera to scan the QR code / barcode on a visitor badge. Details are auto-parsed into the lead form. Tap the ✕ button on the camera view to close it.

Scan Visiting Card — Photograph a visiting card (front side, and back side if needed). Review the capture, tap Finish, and OCR extracts the contact details into the lead form.

Scan from Image — Pick an existing photo of a visiting card saved on your phone or laptop. Follows the same review and OCR flow as the camera scan. Also reads QR / barcode images.

Manual Entry — Type the lead details directly into the full lead form: name, company, designation, contact details, qualification, interest area, requirement and follow-up tracking.

📋 Manage Leads

Dashboard — Home screen with live lead statistics: total leads, follow-ups, qualification split and today's captures.

View Leads — Browse, search and filter all leads. Tap a lead to see full details, edit, or delete. Deleted leads move to Trash.

Trash — Deleted leads are kept here. Admin can restore leads or permanently delete them.

Export — Download lead data (requires export permission from the admin).

👤 My Profile

Change your User ID and password. Your display name is set by the admin. User IDs must be unique — the app checks against the central database before saving. Changes sync to all devices immediately.

🛠️ Admin Features

Event Management — Create and manage events (name, dates, venue). The default event set by the admin applies to all users; every captured lead is tagged with it.

User Management — Add users, set display names, User IDs, passwords, roles and export permission. Custom roles can be added or deleted.

Interest Categories — Manage the interest area options shown in the lead form.

Settings — Company details, lead qualification priorities, dropdown options (visitor types, volumes, timelines, follow-up types and statuses) and the OCR API key.
